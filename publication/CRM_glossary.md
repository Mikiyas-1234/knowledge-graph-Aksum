# CIDOC-CRM Glossary — Aksum Knowledge Graph

Plain-language explanations of every CIDOC-CRM class and property code used in
`nodes.csv`, `asserted_edges.csv`, and `aksum_kg_publication.cypher`.

This glossary is intentionally simplified. Full normative definitions are in the
[CIDOC-CRM specification](https://www.cidoc-crm.org/html/cidoc_crm_v7.1.2.html).

---

## Classes (used in the `crm_class` column of nodes.csv)

| Code | Full name | Used for in this graph | Example node |
|---|---|---|---|
| **E4_Period** | Period | Chronological units — named cultural or temporal phases | `period_classic_aksumite` |
| **E16_Measurement** | Measurement | Radiocarbon dating events; each node stores lab number, material, BP age, and calibrated ranges | `c14_beta1_oxf` |
| **E21_Person** | Person | Individual human agents — rulers, archaeologists | `person_ezana` |
| **E22_Man-Made_Object** | Man-Made Object | Movable manufactured artefacts — coins, stelae, pottery, inscriptions | `object_stele_2` |
| **E25_Man-Made_Feature** | Man-Made Feature | Immovable human-made structures and complexes — tombs, palaces, terraces | `arch_mausoleum` |
| **E27_Site** | Site | Named localities with human activity — settlements, ports, rockshelters, regions | `place_aksum` |

### Note on E16_Measurement

In CIDOC-CRM, `E16_Measurement` is technically an *activity* (measuring something)
rather than a "thing". In this graph, each `E16_Measurement` node conflates the
measurement event and its result into a single node to keep the graph readable.
The properties `bp_age`, `cal_68pct`, `cal_95pct`, and `lab_material` encode the
result. This is a deliberate simplification; a fully normalised CRM representation
would use `E54_Dimension` nodes for the result values.

## Properties (used in the `relation_type` column of asserted_edges.csv)

| Code | Full name | Direction | Used for | Example |
|---|---|---|---|---|
| **P4_has_time-span** | has time-span | `E` → `E52_Time-Span` (approximated here as Period) | Linking a person, object, or measurement to the period it belongs to | `person_ezana` → `period_classic_aksumite` |
| **P7_took_place_at** | took place at | `E7_Activity` → `E53_Place` | *(Not used directly — subsumed into P14i below)* | — |
| **P9i_forms_part_of** | (inverse) consists of | `E4_Period` → `E4_Period` | Temporal sequence: one period immediately precedes the next. Strictly this is a custom shorthand; the CRM would use `E61_Time_Primitive` comparisons. | `period_early_aksumite` → `period_classic_aksumite` |
| **P14i_performed** | (inverse) carried out by | `E` → `E21_Person` | Linking a site to the archaeologist who excavated it | `place_beta_giyorgis` → `person_phillipson_d` |
| **P53_has_former_or_current_location** | has former or current location | `E18_Physical_Thing` → `E53_Place` | Locating an object or architectural feature at a site | `object_stele_1` → `place_stele_park` |
| **P89_falls_within** | falls within | `E53_Place` → `E53_Place` | Spatial containment — one site within a larger region | `place_aksum` → `place_tigray` |
| **PRECEDES** | *(custom)* | `E4_Period` → `E4_Period` | Temporal ordering of periods. Not a standard CRM property; stored as `P9i_forms_part_of` in the CRM column and `precedes` in `relation_label`. | `period_pre_aksumite` → `period_proto_aksumite` |

## Confidence tiers (used in the `confidence` column of nodes.csv)

| Value | Meaning |
|---|---|
| `gold` | Hand-verified against a specific source page. The node_id, label, CRM class, source, and page_ref were all checked by a human reviewer. |
| `automated` | Generated by the NER pipeline (`ner_pipeline.py`). Not hand-verified; treat as provisional until reviewed. |

---

## Evidence types (used in `evidence_type` and `extraction_method` in asserted_edges.csv)

| `evidence_type` | `extraction_method` | Meaning |
|---|---|---|
| `asserted` | `hand_curated` | Relationship verified by hand against a specific source passage. Citable. |
| `asserted` | `regex_match` | Relationship extracted by the pipeline on an explicit relation verb ("found at", "excavated by", etc.) and not contradicted by hand review. Citable with the caveat that regex extraction may mis-parse complex sentences. |
| `candidate` | *(not in asserted_edges)* | Co-occurrence in the same sentence with no explicit relation verb. **Not asserted facts.** Kept in `candidate_edges.csv` for review. |
